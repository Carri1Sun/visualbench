# Attribution and scope
The 20 tasks are inspired by the public sources listed in each SOURCE.md and cases.csv.
The package-authored expanded prompts, translations, fixtures, SVG input assets, scripts and empty starters were created for this request. They are adapted experimental inputs, not verbatim copies of long source prompts, and not official benchmark distributions.

The original short prompt files are small attributed quotes; the black-hole config is archived from a repository whose README declares MIT. Third-party material retains its original rights. Three.js 0.180.0 is distributed with its unmodified MIT LICENSE in vendor/three/LICENSE.

The package does not contain original creators' model outputs, screenshot galleries, confidential system prompts, paid Agent OS templates, commercial game art, commercial music, API credentials or real personal records. Links to source galleries are references, not task input images.
Do not treat the normalized HTML lane as an exact rerun of the source benchmarks. Frameworks, system guidance, assets, task scope and agent tools can affect results.
