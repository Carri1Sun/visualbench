# 08 鼠标搅动彩色流体

Source: https://goldiebench.com/tasks/fluid

## 公开输入与原题环境
公开页面给出一句 WebGL 流体任务并展示结果；原 Agent OS 的完整系统环境未公开。没有必需的图片。

## 本包的处理
本包定义二维染料流体、统一操作与清空状态，避免把普通粒子云当成流体模拟。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
`original-short.en.txt` 仅保留公开页面中的简短原题。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 拖动注入颜色与动量
- 染料被持续流场输运
- 清空和暂停有效
- 近似方法说明诚实且画面持续可见
