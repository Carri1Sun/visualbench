# 05 数字禅意花园

Source: https://www.bridgebench.ai/prompts/6167391e-81b4-4b55-896a-4e48c79c75c8

## 公开输入与原题环境
公开原题是单文件 HTML/CSS/JS，要求可点击圆石、涟漪和五句预定义文字；没有图片输入。

## 本包的处理
新增五句统一文字及连续点击要求；这些文案不是原题附带素材。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
完整公开原题请通过上方来源链接查看；本目录不冒充原始项目或原文备份。

## 预置文件
assets/phrases.json

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 圆石、文字和背景层次清楚
- 每次点击可触发反馈
- 连续点击不堆积错误状态
- 键盘可使用
