# 20 关系图谱分析工作台

Source: https://www.bridgebench.ai/prompts/7262b063-142d-4266-a0c4-005e3c930e9c

## 公开输入与原题环境
原题是一套全栈 OSINT 平台说明，包含数据摄取、数据库、搜索、地图及实时来源；不能仅靠一句短 prompt 或零依赖 HTML 重现全部范围。

## 本包的处理
主包缩小为前端工作台，提供虚构实体、关系、位置和事件。本包新增素材，不是原站真实数据；无数据库、账号、API 密钥要求。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
完整公开原题请通过上方来源链接查看；本目录不冒充原始项目或原文备份。

## 预置文件
assets/investigation.json

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 四类视图使用同一数据源
- 实体选择跨视图联动
- 筛选及清除选择一致
- 虚构数据有明显标注，详情无错配
