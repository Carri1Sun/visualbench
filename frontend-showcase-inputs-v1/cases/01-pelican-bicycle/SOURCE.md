# 01 鹈鹕骑自行车

Source: https://simonwillison.net/2024/oct/25/pelicans-on-a-bicycle/

## 公开输入与原题环境
原题是很短的 SVG 绘图请求，没有要求提供参考图或项目。

## 本包的处理
为统一画廊展示，本包让 SVG 内嵌在 HTML 中；保持绘图题，不提供现成鸟或自行车图形。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
`original-short.en.txt` 仅保留公开页面中的简短原题。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 能辨认鹈鹕和自行车
- 座位、踏板、脚、车把之间关系合理
- 完整构图不被裁切
- SVG 可缩放且没有外部图片
