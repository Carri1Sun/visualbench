# 15 浏览器桌面操作系统

Source: https://goldiebench.com/tasks/webos

## 公开输入与原题环境
公开一句任务要求窗口、Dock、Notes/Paint/Terminal；未提供起始项目或设计图，原 Agent OS 系统模板未公开。

## 本包的处理
明确三种应用的最低功能与模拟终端边界，新增保存、重置和窗口管理要求。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
`original-short.en.txt` 仅保留公开页面中的简短原题。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 三种应用有实际功能
- 窗口焦点、缩放和最小化有效
- 记事内容刷新后保留
- 模拟终端和重置状态正确
