# 11 复古霓虹赛车

Source: https://goldiebench.com/tasks/outrun

## 公开输入与原题环境
公开页面给出一句伪 3D 驾驶游戏任务；Agent OS 的完整系统模板没有公开，没有图片输入要求。

## 本包的处理
新增固定操控、自动演示和回放规则；不复制原游戏素材或原站模型成品。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
`original-short.en.txt` 仅保留公开页面中的简短原题。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 公路透视和速度感成立
- 输入实际改变车辆状态
- 速度距离由运行状态产生
- Demo 与 Restart 有效
