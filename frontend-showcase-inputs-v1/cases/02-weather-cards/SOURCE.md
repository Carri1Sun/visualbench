# 02 四种天气动画卡片

Source: https://www.reddit.com/r/LocalLLaMA/comments/1jiqi81/new_deepseek_v3_vs_r1_first_is_v3/

## 公开输入与原题环境
公开帖给出单 HTML 的天气卡片提示词并展示模型结果；没有提供输入设计图。

## 本包的处理
保留四种天气与深色背景；增加统一的暂停和重播操作，便于比较动效。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
完整公开原题请通过上方来源链接查看；本目录不冒充原始项目或原文备份。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 四种天气可辨认且动画各不相同
- 卡片视觉风格一致
- 暂停和重播有效
- 窄屏无水平溢出
