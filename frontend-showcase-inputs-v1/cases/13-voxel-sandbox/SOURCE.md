# 13 迷你方块沙盒

Source: https://goldiebench.com/tasks/voxelcraft

## 公开输入与原题环境
公开任务要求 Minecraft 风格的放置/破坏方块及昼夜；没有用户设计图，完整 Agent OS 系统环境未公开。

## 本包的处理
限定小型世界、原创程序化材质；增加视口内操作反馈。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
`original-short.en.txt` 仅保留公开页面中的简短原题。

## 预置文件
无题目专属素材。

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 世界主体正常渲染
- 可以放置和删除被指向方块
- 材料选择真正生效
- 输入、指针锁定退出和重置有效
