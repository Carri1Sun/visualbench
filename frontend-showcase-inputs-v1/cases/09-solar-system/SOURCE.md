# 09 交互式太阳系

Source: https://www.bridgebench.ai/prompts/c95d2701-dd99-434c-8af0-f5caf03975dd

## 公开输入与原题环境
原题有很长的任务说明，允许 agent 使用文件、命令和浏览器工具，偏好 React/TypeScript/Vite；要求程序化/本地素材，不依赖天文 API。

## 本包的处理
缩小为太阳与八大行星的教学演示，提供近似固定参数；不包含原题的全部轨道、音频或验证要求。

`prompt.en.txt` / `prompt.zh.txt` 是本包独立撰写的完整测试版，不是原文全文转载。
`short.en.txt` / `short.zh.txt` 是本包的一句版本，要求范围小于完整版本。
完整公开原题请通过上方来源链接查看；本目录不冒充原始项目或原文备份。

## 预置文件
assets/planets.json

本包新增的数据、文案和 SVG 输入素材均标为新增内容；它们不是原作者使用过的素材。
`starter` 是空白运行模板，没有题目答案、设计稿或已实现的交互。

## 验收观察
- 太阳和八大行星均可见
- 相对公转周期来自数据
- 选择行星显示正确事实
- 暂停、调速、重置有效
