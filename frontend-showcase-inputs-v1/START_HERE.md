# 给 coding agent 的入口

用户目标：施工一个前端展示页，用同一组任务比较多个模型的设计方案、最终视觉与交互效果、部分逻辑代码。每题每模型默认展示 5 次独立生成。

请先读 `CODING_AGENT_GUIDE.md`，然后读 `README.md`、`manifest.json`、`OUTPUT_DATA_CONTRACT.md`。
20 道题的真实输入已在 `cases/` 与 `ready-prompts/`，本包还没有参赛模型的生成结果。
空模板与输入素材不可当成模型结果展示。

如果用户只让你搭建展示页，先完成数据导入、浏览、对比和真实运行预览。接入模型生成器需要用户提供或配置模型访问方式；不编造模型输出或评测成绩。
如果用户另行授权你批量生成，用同一提示、语言、工具权限与预算为每个模型生成五次，并保存实际请求和结果。
