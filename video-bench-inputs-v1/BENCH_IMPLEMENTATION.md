# 视频 Bench 施工规范

## 目标与边界

将 20 道固定输入题交给不同 coding model/agent，实现可运行 Remotion 源码及视频，并直观呈现同题每模型 5 次结果。显示的是实际产物、成功率和重复运行差异。输入素材不作为输出；本包不提供成片答案或自动审美真值。

本套是对公开任务的统一 Remotion 改写。原作可能使用 HyperFrames、Canvas 或其他工具；不得把本套成绩描述为原工具或原作者 prompt 的原样复现。任务的 source_kind 表示来源性质，不表示生成过程必然 one-shot。

## 数据与文件结构

- 不改动 input pack。读 manifest.json 得到 cases 数组，每题 id 稳定。
- 结果存到独立 runs/<model-slug>/<case-id>/run-01..05/。
- 用 prepare_case.py 建立每次运行；文件路径统一为 public/input/。
- 每次完成后保存 run.json（见 schemas/run.schema.json）和项目源码；如果失败，也生成状态和日志记录。
- 建议额外维护 results-index.json，指向所有 run.json。展示页只消费结果，不重新运行模型。
- source_url 供研究者查证，固定输入基线不传给评测 worker。prepare_case.py 不复制 SOURCE.md。

## 一次运行的定义

一次 run = 新的独立工作目录 + 同一初始提示词 + 同一输入版本 + 一个完整 agent 会话。agent 可在统一预算内编译、预览、定位错误、修改和再次渲染；这些都计入同一次 run。仅发一次初始 prompt 不意味着底层只调用模型一次，也不意味着成片未经迭代。

五次 run 必须相互独立。记录所有失败，不能挑选最好的一次代替 5 次。按模型记录实际 temperature/seed；API 不支持时用 null，不能伪造采样参数。

同一比较组固定：prompt 语言、所有输入哈希、依赖锁文件、硬件/渲染参数、harness、工具权限、skill 版本、预算与迭代政策。预热依赖安装可统一排除在生成成本之外，实际策略写入 protocol 字段。

## 结果展示建议

1. 题目页：标题、简短任务、输入模式、尺寸/时长、输入预览、来源说明。
2. 模型行：五张等尺寸视频卡，保留失败位置和实际错误原因。
3. 全局时间轴：将所有片段 seek 到同一秒数，提供同步播放/暂停、0.25x/0.5x/1x。不同题不混在同一时间轴。
4. 声音默认只开启一张卡，避免五路音乐叠加；支持切换试听。
5. 点开单次结果：完整视频、分镜方案、关键帧、源代码、耗时/token/费用、构建和渲染状态。
6. 03/13 的透明母版在深色、浅色或棋盘格背景上预览；H.264 预览不承载 alpha。
7. 支持隐藏模型名的盲看模式；用户选择和评分需要落库时再接后端，静态首版可导出 JSON。

## 验收分层

技术层：依赖可安装、TypeScript 可检查、完整时长可渲染、尺寸/帧率正确、输入无缺失、无黑屏/离线素材错误、音轨存在性符合任务。脚本 verify_outputs.py 只检查媒体技术元数据；它不能判断语义和审美。

任务层：逐题 task.json 的 checks，由评审实际播放核对；数字、地理、GPX、分支路径及字幕同步要单独检查。

视觉层：构图/排版、运动质量、信息层级、视觉一致性、节奏与叙事、音画协调。可以盲选偏好或独立打分；不要把执行成功率直接换算成审美分。

保留原始观测。原生不会输出 token/费用的 harness，字段用 null。生成成功但渲染失败、渲染成功但任务不完整应分别标记。不要凭视频截图宣称整段无错。

## 四档视频指导强度的后续扩展

当前 20 题是前一轮的具体任务集合，不是 4 档×同题的受控实验。未来需要比较指导强度时，为同一个 subject 建立 variant_id：free、script、spec、reference。分别逐层加入脚本、规范、分镜/参考，不改变底层主题与核心素材，单独冻结每个 variant 的哈希。不要直接把本套不同主题的题目视为四档之间的因果对照。

## 技术栈

输入项目使用 React 19.0.0、Remotion 4.0.532、TypeScript 5.8.3。推荐 Node.js 22 或更高与 npm。包不含 node_modules、浏览器二进制和模型调用密钥。首次 npm ci/浏览器准备需要联网；素材本身已包含在包内。Remotion 自身许可证由上游决定，见 https://www.remotion.dev/license 。

可用自选前端栈构建展示站。当前任务只交付输入包，无发布站点、调用付费模型或把素材提交给第三方平台的操作。
