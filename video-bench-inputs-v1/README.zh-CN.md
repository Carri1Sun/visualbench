# 视频 Bench 输入包 v1.0

只包含对话中筛选的 20 道视频题；不含最初的 20 道网页题。按本包配置，01、06 两题为纯 prompt，其余 18 题配有素材/数据文件。纯 prompt 仍需 coding agent、Node/Remotion 环境，以及编译渲染过程。

**给 coding agent 的入口：AGENT_START_HERE.md。**

## 你拿到的是什么

- 20 套中英对照测试提示词、逐题输入清单与验收项。
- 真实素材文件：Logo、品牌 brief、HTML/PNG UI 参考、原创新闻截图、音频、口播视频/遮罩、字幕、GPX、地图、图表/排名/流程 JSON。
- 统一 Remotion + React + TypeScript 起始项目和 package-lock.json；不包含各题视频实现答案。
- 单题隔离初始化脚本、完整性校验脚本、输出技术检查脚本、benchmark 展示页施工文档和单次结果 schema。

## 关于一句 prompt

“只发一次初始 prompt”可以启动一个多步 agent 工作流；agent 仍需写代码、安装依赖、渲染和修复。原始公开作品中有多轮改进示例。这个包不承诺任何模型 one-shot 成功。

原帖引用作者本地文件时，文件往往没有公开，例如跑步 GPX、新闻截图、产品项目、音乐。为了让你的 agent 实际开工，本包提供了明确标注的原创或可获取替代输入。所有 task prompts 都是统一改写，未冒充原文。

## 快速开始

```bash
python3 scripts/verify_pack.py
python3 scripts/prepare_case.py 06 ../runs/model-a/06/run-01
cd ../runs/model-a/06/run-01
npm ci
# 将 PROMPT.md 交给 coding agent，完成后：
npm run typecheck
npm run render
```

建议 Node.js 22+、npm、Python 3；完整性媒体检查与输出检查另需 ffprobe。首次依赖和浏览器准备需要网络，但本包创意素材不需要再次下载。纯素材校验只用 Python 标准库。

## 输入替代范围

- 07–09 使用原创虚构 Waypoint 官网、UI 和版本日志；不是 Presscut 或 Linear 原始项目。
- 10 使用原创脚本和固定合成旁白。逐词时间来自自动对齐，文字按原脚本校正；小时间误差不计为审美差异。
- 11 使用公开绿幕测试视频，附遮罩/透明前景；是绿幕合成版本，不评测自然背景人物分割。转录为自动草稿。
- 12 是原创虚构文章截图，不包含实际新闻事实。
- 15 的图片/视频是风格化矢量风景，非实拍素材。
- 16 的世界地图是简化地理示意图；17 的 GPX 与街区地图为合成数据。
- 18 的游戏、销量、封面全部虚构；19 的六个月数据与原题数值对应。
