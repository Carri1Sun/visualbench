# 17-run-story — Run Story

Read run.gpx and map.json. Make a 20-second vertical story replaying the complete synthetic run in compressed time. Draw the route on local-map.svg, move a runner marker, and update elapsed time, cumulative distance and average pace from the GPX. Clearly distinguish real run elapsed time from video time. End with an accurate summary.

1080 × 1920 · 30 fps · 20 s · 600 frames

## Supplied files (relative to public/input/)

- `local-map.svg`
- `map.json`
- `run.gpx`
