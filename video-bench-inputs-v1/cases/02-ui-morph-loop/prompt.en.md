# 02-ui-morph-loop — Ui Morph Loop

Read states.json. Create a 16-second seamless loop in which ONE persistent shell morphs through the eight UI states in order. A visible cursor motivates clicks and drags. The shell must preserve spatial continuity; transition internal content without hard-cutting the shell. Use beat.wav and align major changes to its 120 BPM pulse. Return to the initial visual state at the loop boundary.

1080 × 1080 · 30 fps · 16 s · 480 frames

## Supplied files (relative to public/input/)

- `beat.json`
- `beat.wav`
- `states.json`
