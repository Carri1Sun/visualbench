# 18-ranking-towers — Ranking Towers

Read ranking.json and covers/. This is fictional benchmark data, not a real game-sales ranking. Create a 30-second 3D ranking film in which tower height is proportional to copies sold. Visit entries from rank 20 to rank 1 with a smooth camera, showing each name, cover and value. Keep a consistent height scale and give the winner a clear final reveal.
