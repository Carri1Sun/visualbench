# 09-release-notes — Release Notes

Read changelog.md and the before/after UI references. Create a 30-second release announcement. Select the three most useful user-facing changes, show what changed, and explain the benefit in plain language. Keep release name and date exact. Smaller fixes may be omitted. End with the provided update CTA.

1920 × 1080 · 30 fps · 30 s · 900 frames

## Supplied files (relative to public/input/)

- `brand.json`
- `changelog.md`
- `fonts/DejaVuSans.ttf`
- `fonts/LICENSE.txt`
- `logo.svg`
- `screenshots/after.png`
- `screenshots/before.png`
- `source-ui/after.html`
- `source-ui/before.html`

See the execution contract in PROMPT.md after preparation.
