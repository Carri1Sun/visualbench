# visualbench

[English](README.md) | [简体中文](README.zh-CN.md)

Scores and pass rates alone do not give most people a clear picture of what a model or agent can actually do. visualbench aims to address this by helping people better understand model capabilities.

完整的本地启动、600次运行协议、结果目录与 Pi trajectory 下载说明见 [中文文档](README.zh-CN.md)。
