# VisualBench 展示站

本轮展示前端由本地 Pi Agent（openai/gpt-6.1-sol，thinking=max，全新隔离工作目录）实际编写 React 核心。Pi 施工进程在 45 分钟到达约定截止时间后结束；Codex 保留全部已生成核心代码，完成样式、追加需求集成、构建与真实浏览器验收。施工过程与 600 个参赛运行独立，详情见 `src/BUILD-PROVENANCE.json`。

## 启动

- 安装：`npm --prefix app install`
- 开发：`npm --prefix app run dev`
- 构建：`npm --prefix app run build`
- 构建预览：`npm --prefix app run preview`

页面仅绑定 `127.0.0.1:4173`。数据服务由根目录的 benchmark 工具在 `127.0.0.1:4174` 提供。Vite 代理 `/data`、`/results`、`/inputs`。

## 已实现

- 真实目录、结果、运行轨迹及输入校验每 10 秒同步；无模拟结果或输入素材冒充输出。
- 40 题、5 模型、3 次重复形成 600 个运行位，统计来自 API；失败、等待和较弱产物全部保留。
- 模型进度 dashboard、题目网格、类型/模型/类别/输入方式/运行次数/状态/搜索筛选。
- 每题模型行与三次运行列，真实截图与视频、公开方案、完整输入、源码、技术记录。
- 2–4 个结果并排、稳定匿名标识、同步播放/暂停/定位、倍速、单路音频；视频加载失败可切换主时钟。
- 原生 Pi JSONL 与离线 HTML 轨迹查看和下载，下载名包含模型/题目/运行身份，所有会话与尝试可追溯。
- 浏览器本地人工失败标记与自由备注、撤销、JSON 导出；标记按轮次隔离，保持 runner 状态与原始产物。
- 独立 origin 交互预览，保留 localStorage 和素材读取；同 origin 环境禁用 iframe 预览。
- 桌面与移动布局、错误状态、键盘操作、弹窗焦点管理。
